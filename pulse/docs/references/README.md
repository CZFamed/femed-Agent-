## 3. 归档规则（对后续所有 agent 生效）

1. 凡被代码或治理文档**当作依据引用**的文件（调研报告、方案、风格报告、原始需求稿），
   必须有一份放在稳定位置：要么入库，要么在本目录留副本，并在 §1 登记。
2. **不要把依据文档留在** `Documents\Codex\…\outputs\`、微信接收目录、桌面这类临时位置——
   本次丢失就是因为报告只存在于仓库外，且路径从未写进任何入库文件。
3. 归档时**不改内容**（保持可核对）；要改口径就改引用它的代码，并在本表登记。
4. 引用外部文档时，用**本目录的相对路径**或工作区相对路径，不要写机器相关的绝对路径。
