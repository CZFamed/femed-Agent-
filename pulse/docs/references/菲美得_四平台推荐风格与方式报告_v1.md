## 0. 三句话结论

**第一句：四个平台不是四种排版，是四种说服顺序。**
同一条文案发四遍，等于四个平台都只发挥了 30%。菲美得的差异化卖点是「铸件 + 粗加工一体化」，而这个卖点在不同平台需要的"证据形态"完全不同——LinkedIn 要设备与检测数据，Facebook 要工厂画面，TikTok 要浇注那一刻的冲击力，VK 要长图文企业介绍。

| 平台 | 说服顺序 | 首帖任务 |
| --- | --- | --- |
| **LinkedIn** | 先证明能力 → 再谈采购 | 让采购把我方放进"可询价名单" |
| **Facebook** | 先建立存在感 → 再进群组 | 让人记住"中国有这家消失模厂" |
| **TikTok** | 先用画面抓人 → 不谈采购 | 品牌曝光与行业影响力 |
| **VK** | 先做俄语区企业形象 → 再进采购 | ✅ 法务评审已通过，正式运营 |

**第二句："零修饰"改变的是方式，不是顺序。**
取消的是后期环节，不是策略：图片不再裁、不再调色、不再烧字；说明文字全部搬到平台**文案栏（caption）**；画幅在**拍摄时**用手机相机的比例选择器直接定死。这条指示反而让执行变简单了——原来最耗人的一步（做图）直接消失。

**第三句：当前人手条件下，四个平台全部可以零剪辑发布。**
不需要剪辑、不需要配音、不需要字幕处理。每帖只要有"几张拍好的原图 + 一段写好的文案"就能发。真正的工作量在**写文案**和**拍对画面**，不在后期。

## 1. 平台优先级是怎么定的（不是拍脑袋）

### 依据一：客户自己在用什么平台

已有的一手证据——Takumi USA（Hurco 集团，NASDAQ: HURC）在其官方新闻稿中自列社媒渠道为 **Facebook / Instagram / LinkedIn / YouTube**（另有 X）。

> 这就是机床整机厂的真实平台分布：**LinkedIn 为主，FB/IG 为辅**。不是我们觉得哪个平台好，而是客户就在那里。

### 依据二：谁做决定

机床厂买铸件，走的是**采购与供应链**部门，不是市场部。已定位的联系人证据（Lokesh 侧）为 Purchase Manager、purchase@ 邮箱、Senior Manager。

> 含义：内容是给**采购经理、供应链总监、制造工程师**看的。他们关心单重范围、材质牌号、公差、探伤标准、月产能、交期、包装、单证——**不看形容词，看参数**。

`Pulse需求校准_B2B工业铸件场景.md` §2 已给出重排结论，本报告沿用：

### 2.2 四条平台机制（决定了文案必须怎么写）

**机制一｜LinkedIn 是"折叠后说服"。**
只有前 3 行被看到，之后的全部被"…展开"挡住。所以第一行必须直接给出**对方的利益**（"你不用再对接两家供应商"），而不是自我介绍（"我们是一家成立于…的公司"）。把这个顺序写反，后面写得再好也没人看到。

**机制二｜Facebook 是"降权外链 + 奖励对话"。**
带链接的帖子触达明显更低。做法：**正文不放链接**，链接放第一条评论，并用一个提问收尾换评论。这不是技巧，是平台的机制导向。

**机制三｜TikTok 是"前 3 秒定生死"，且画面优先于文字。**
任何"本公司专业生产…"式的开场在 TikTok 都等于自杀，开场必须是画面冲突或反常识陈述。而且 TikTok 的受众是**同行与爱好者**——所以在 TikTok 上求"专业感"没有意义，求"这道工序真好看"才有意义。

**机制四｜VK 是"企业形象 + 直接触达"，也是四平台中唯一的非英语平台。**
VK 长文案接受度高、外链降权轻——官网链接可以直接放正文，适合承载"企业介绍 + 能力清单"这类内容。代价是每帖都要**从英语母版翻译成俄语并审校**，这比其余三个平台多一道工序，安排节奏时要把这道工序算进去。

> ⚠️ **零修饰带来的一个直接后果**：原方案在 TikTok 上靠"图内烧字幕"承担信息，现在图上一律无字，**信息必须全部由 caption 承担**。所以 TikTok 的 caption 要写得比原来更完整一点（但仍控制在 150 字符内 + 标题式钩子）。

## 3. 逐平台详解

### 3.1 LinkedIn｜"折叠后说服"

#### 谁在看

采购经理、供应链总监、制造与工艺工程师、工厂主。这是**唯一能精准触达决策链的平台**，也是客户（机床整机厂）本身在用的主平台。

#### 平台奖励什么

- **停留时长**：多图帖、文档轮播让人多停几秒，算法就给更多分发。
- **惩罚外链**：正文里的链接会明显降低触达 → 链接放**第一条评论**。
- **奖励讨论**：结尾提问能带起评论，评论量是 LinkedIn 最有效的放大器。

#### 风格规范

| 维度 | 建议 |
| --- | --- |
| 语气 | **工程语言、参数导向、克制、可信**。禁止 "world-class / leading / No.1 / best price" 这类无法证实的形容词 |
| 人称 | 用 **We / Our**，不用 "I"（公司页发布）；正文里可以出现"你"（you），因为要讲对方痛点 |
| 长度 | 600–1,200 字符 |
| 第一行 | 必须是**对方的利益或痛点**，不是自我介绍。例：`Most machine tool builders don't own a foundry.` |
| 段落 | 每段 1–2 行，段间空行。**不要**写成一整块 |
| 分点 | 能力证据必须分点写（CASTING / MACHINING / VERIFICATION / FINISHING），采购是扫读的 |
| Emoji | 0–2 个，只做功能型分隔（→ ·），不做表情 |
| 标签 | 3–5 个品类词：`#casting #foundry #lostfoam #machinetools #cncmachining` |
| 视觉 | 多图 3–5 张，**统一 4:5**（拍摄时设定，不后期裁）；图与图之间要有"递进"（设备 → 加工 → 检测 → 包装） |
| 外链 | ❌ 不放正文 |

#### 方式（怎么做）

**拍什么**：3–5 张 4:5 原图，按"能力递进"顺序排列——

1. 精加工成品 + 数控机床同框（**最重要的一张，直接证明"铸 + 加工"同厂**）
2. 大型数控镗铣床正在加工厚壁箱体
3. 三维扫描 / 三坐标检测画面（质量能力证据）
4. 缠膜上托、待发状态的成品（交付能力证据）

> **工程落地**：上述四个"位次"已固化为 `pulse/services/media/platforms.py` 的 `ShotSlot`（LinkedIn 4 格），控制台按位次逐格召回，挑不到就提示补拍。

**怎么发**：

| 项 | 建议 |
| --- | --- |
| 发布主体 | 公司主页；**同时用真实岗位账号转发**（个人号触达远高于公司页） |
| 时间 | 周二至周四 09:00–11:00（目标市场印度 IST 为准） |
| 正文 | 上述六段结构，槽位未核实的一律删除，不估算 |
| 链接 | 放**第一条评论**，自己发 |
| 第一条评论 | `Capability sheet here → [link] · Casting + pre-machining from one plant in Cangzhou, China.` |
| 可见性 | PUBLIC |

**发完 48 小时做什么**：

1. **第 1 小时**：给 5–10 位目标联系人（印度整机厂采购/供应链）单独发一条**不带链接**的私信，提及帖子中的具体细节（例如"床身 + 粗加工同厂"）。
2. **第 4 小时**：在评论里追加一条"工艺细节"（白模 → 浇注的工段照片），把讨论从"看产品"引到"看工艺"。
3. **第 24 小时**：回复全部评论；把问到参数的问题整理成第 2 帖（工艺过程帖）。
4. **第 48 小时**：统计**主页访问与 DM 数**，记入看板（B2B 口径，不看点赞数）。

#### 该做 / 不该做

| ✅ 该做 | ❌ 不该做 |
| --- | --- |
| 第一行讲对方痛点 | 第一行自我介绍 |
| 能力证据分点、可核验 | 堆砌形容词 |
| 链接放评论区 | 正文带链接 |
| 结尾提问 | 结尾只说"欢迎联系" |
| 图统一 4:5 直拍原图 | 混比例、加图内文字、加边框 |

### 3.2 Facebook 主页｜"存在感 + 为群组铺路"

#### 谁在看

泛行业受众、同行、区域社群、群组成员。渠道价值主要在**群组**（`machining` / `manufacturing` / `CNC` 类），主页本身是"名片"，而不是获客入口。

#### 平台奖励什么

- **原生视频**（直接上传，不要粘 YouTube 链接）。
- **外链强降权**——比 LinkedIn 更狠，正文一条链接可能让触达腰斩。
- **评论与提问**：带问题的帖子互动明显更好。

#### 风格规范

| 维度 | 建议 |
| --- | --- |
| 语气 | 比 LinkedIn 更口语、更有画面感，但仍克制 |
| 长度 | 150–400 字符；前 **2 行**决定是否被展开 |
| 结构 | 场景描述（3 段内）→ 一句结论 → **提问收尾** |
| Emoji | 2–4 个，可以有一个"🔥 / 🏭"这类画面型 |
| 标签 | **只 1–2 个**（过多降权）：`#casting #machining` |
| 视觉 | 有视频发原生视频（**9:16 拍摄**）；无视频就发 3–5 张 4:5 原图 |
| 外链 | ❌ 一律不放正文 |

#### 方式（怎么做）

**形态一：原生短视频（首选）**

- 直接上传原始片段，**不剪、不拼、不配乐、不加字幕**。
- 封面用**视频首帧**即可（零修饰下不再单独做封面图）。若平台强制选封面，就在视频里拖到浇注那一刻截一帧。

**形态二：图集（备用，当天不想动视频时用）**

- 3–5 张 4:5 原图 + 同一段文案，效果略弱但可接受。

**怎么发**：

| 项 | 建议 |
| --- | --- |
| 时间 | 工作日 12:00–14:00 或 19:00–21:00（受众当地时区） |
| 付费推广 | 首帖不做，先用自然流量测内容形态 |
| 群组分发 | 同一素材以**纯分享形式**发到 2–3 个机加工/制造群组，文案改短，不带任何链接 |

**发完做什么**：把同一条视频以纯分享形式发到 2–3 个制造类群组（**先人工确认版规**，这属于半自动链路），文案改短、不带链接。

#### 该做 / 不该做

| ✅ 该做 | ❌ 不该做 |
| --- | --- |
| 原生上传视频 | 粘 YouTube 链接 |

### 3.3 TikTok｜"前 3 秒定生死"

> **项目基线定位**：P2 / 暂不投入（契约中 TikTok 不进入 `Platform` 白名单，不建发布链路）。原因是受众以**同行与爱好者**为主，转化为询盘的路径极弱；且企业 API 审计周期 2–6 周属纯成本。
> **本节按内容侧给出风格与方式**；素材可备，但不建自动发布链路。

#### 谁在看

同行从业者、机加工爱好者、学生、泛制造兴趣人群。**不是采购。**

#### 平台奖励什么

- **完播率**：这一条压倒一切。
- **趋势音效**：用平台当时的热门音，配乐必须在**应用内**选（商业账号只能用 `Commercial Sounds` 库，普通曲库会触发版权限制）。
- **画面优先**：文字说明几乎不影响分发，画面决定一切。

#### 风格规范

| 维度 | 建议 |
| --- | --- |
| 语气 | 直白、画面驱动。**不谈采购**，不谈产能 |
| caption 长度 | **≤150 字符**；首行即钩子 |
| 结构 | 钩子（首行）→ 一句结论 → 4–5 个标签 |
| Emoji | 1–3 个，服务于情绪（🏭 🔥） |
| 标签 | **4–5 个**：`#casting #foundry #cnc #machining #manufacturing #satisfying` |
| 视觉 | **9:16 竖屏**（图片轮播与视频统一用竖屏拍摄） |
| 主页 | 简介写明 `Castings + machining, Cangzhou China`，并挂官网链接（**TikTok 主页是唯一的链接入口**） |

#### 方式（怎么做）

**形态一：图片轮播（Photo Mode）—— 零压力可执行形态**

- 上传 **5–6 张 9:16 竖屏原图**，按工艺流程排序：浇铸 → 白模 → 喷丸件 → 加工 → 检测 → 待发。
- **图上一律不加字**（零修饰要求）。原方案烧在图上的英文说明，现在改写到 caption 里。
- 轮播配乐：发布时在**应用内**选一首 `Commercial Sounds` 库的曲目，手机操作约 10 秒，不需要后期人员。

**形态二：短视频（待条件具备后再上）**

- 每段 **8–15 秒**，一条只拍一个动作，竖屏拍摄。
- 实测较优时长区间约 **21–34 秒**（多段拼接时）。
- 零修饰下**不加字幕也成立**——说明性内容由 caption 承担。

**caption 模板**（可直接改）：

```
From foam pattern to machined casting — one factory, no handoffs 🏭
5 steps, swipe →
#casting #foundry #cnc #machining #manufacturing
```

**预期与边界（务必对齐预期）**：`#cnc` `#machining` 有流量，但受众是同行与爱好者，**转化为询盘的路径极弱**。因此 TikTok 的定位是**品牌曝光与行业影响力**，不进入询盘 KPI。

#### 该做 / 不该做

| ✅ 该做 | ❌ 不该做 |
| --- | --- |
| 首行就是钩子 | "本公司专业生产…"式开场 |
| 配乐在应用内选 | 用外部音乐（版权风险） |
| 竖屏拍摄 | 横屏素材直接发 |
| 把它当曝光，不当询盘 | 用曝光数据去证明获客能力 |

## 5. 视觉与形式规范（零修饰统一口径）

| 项目 | 规范 | 说明 |
| --- | --- | --- |
| **拍摄方向** | **竖着拿手机** | 横屏素材发到竖屏平台基本等于废片 |
| **画幅** | 拍摄时用相机比例选择器设定：**4:5**（LinkedIn / Facebook / VK）、**9:16 竖屏**（TikTok） | 从源头解决，不依赖后期裁切 |
| **增强功能** | **全关**：美颜、滤镜、AI 优化、场景识别、HDR 增强、人像模式、夜景模式 | 用最普通的"照片"模式 |
| **水印 / 贴纸 / 图内文字** | **一律没有** | 文字全部走 caption |
| **调色** | **不做** | 原图直出 |
| **照片数量** | LinkedIn / Facebook / VK：3–5 张（4:5）；TikTok 轮播：5–6 张（9:16） | 太少撑不起"能力递进"，太多没人看完 |
| **视频时长** | 单段 8–15 秒；拼接后约 21–34 秒 | 一条只拍一个动作 |
| **镜头** | 每次开拍前**擦镜头** | 手机镜头常有油污，这是"糊片"最常见的原因 |
| **光线** | **不逆光**（不对着大门、窗户、天窗拍） | 主体全黑是原图直出最大的敌人 |

> **最关键的一句**：零修饰最大的敌人不是"没修图"，而是**糊、抖、逆光、构图乱**。
> 原图直发完全没问题，但一张拍糊了的原图，比一张修过的图更伤专业形象。
