## 1. 老板指定的模板站，各自是什么

### 1.1 赤野科技 chiyekeji.com（河北驰业网络科技，沧州运河区）

案例分两类：**营销型网站**（内贸）与**外贸案例**（出口）。

外贸案例栏目下直接列出客户**真实上线域名**，共 16 个以上，其中与菲美得高度同类的有：

| 客户站 | 行业 | 与菲美得的相关度 |
|---|---|---|
| bohansivalve.com | 阀门（蝶阀/闸阀/止回阀/球阀） | ★★★★★ 同为工业件出口，含询盘与 WhatsApp |
| ysmetalstampingparts.com | 金属冲压件、搅拌车配件 | ★★★★★ 同为机械零部件出口 |
| juneng-pipeline.com | 法兰/弯头/三通/异径管 | ★★★★☆ 产品分类+应用场景结构可复用 |
| kunshenglonglift.com | 起重设备 | ★★★☆☆ |
| zhongbeitransformer.com | 变压器 | ★★★☆☆ |
| sairuiautoparts.com / hongchenautoparts.com | 汽车配件 | ★★★☆☆ |
| fcykjx.com（元坤机械） | 粮食机械（内贸） | ★★☆☆☆ 内贸站结构参考 |

**这些真实站点的共同结构（实测）**

- 一级导航：`HOME / ABOUT US / PRODUCT / SCENE（应用场景）/ BLOGS 或 NEWS / CONTACT US`
- 首屏：英文一句话价值主张 + 产品关键词 + 询盘入口
- 产品按品类分卡片，进入产品内页有规格与询盘按钮
- 独立「SCENE 应用场景」栏目（菲美得可直接对应工程机械、矿山、铁路、石油等）
- 博客/新闻用于 Google 收录
- 全站悬挂 `WhatsApp` 悬浮按钮 + 询盘表单

> 这是**当前外贸机械配件站的标准打法**，也是菲美得最该用的结构。

## 2. 模板对比：到底该选哪一家

| 维度 | 赤野科技（驰业）系 | 益商EIMS xy 系 |
|---|---|---|
| 是否能看到真实上线效果 | ✅ 能看到同行业客户的成品站 | ❌ 只有效果图 |
| 外贸站成熟度 | ✅ 已有 16+ 个出口客户站，模板经过实战 | ⚠️ 模板较旧（2022 年），未见行业案例 |
| 行业匹配度 | ✅ 阀门、冲压件、管道等同属工业配件 | ⚠️ 通用型企业站 |
| 本地服务 | ✅ 沧州本地公司，可上门沟通维护 | ❌ 异地平台，多为自助建站 |
| 结构短板 | 无 | ❌ 缺制造能力／资质荣誉／应用领域 |

**推荐做法**：以赤野科技外贸案例线为蓝本招标，让服务商提供与 `bohansivalve.com` / `ysmetalstampingparts.com` 同级或同源的模板，并明确要求补齐菲美得专属栏目（见第 5 节）。

> 补充：驰业科技的友情链接里出现 `泊头市兴天环保设备有限公司`、`泊头市三龙五金制品有限公司` 等泊头本地企业，说明其在泊头铸造/机械圈已有服务案例，沟通成本低。

## 3. 参考官网拆解：山西华翔集团（huaxianggroup.cn）

华翔是铸造行业的标杆上市公司，官网结构最值得菲美得直接借鉴。

**完整栏目树（实测）**

```
首页
├─ 关于华翔：公司简介／企业文化／企业荣誉
├─ 新闻资讯
├─ 产品中心：白色家电零部件／汽车零部件／工程机械零部件／其他产品
├─ 技术实力：铸造设备／加工设备／检测设备
├─ 诚聘英才：人才理念／校园招聘／社会招聘
├─ 客户服务：全球布局／合作伙伴／联系我们
└─ 投资者关系：公司公告／实时股价
   语言：CN / EN 双语切换
```

**值得抄的三点**

1. **产品中心按下游行业分类**，而不是按材质分类——采购商是拿着「我做什么设备」来找供应商的。菲美得应对应：工程机械配件／矿山机械配件／石油机械配件／铁路配件／电梯与减速机配件／通用机械件。
2. **技术实力单独成栏，且按设备分**：铸造设备 / 加工设备 / 检测设备。菲美得有消失模造型线、中频电炉、机加工、涂装线、光谱分析仪、三坐标、探伤、拉力与低温冲击试验机，素材完全够撑起这一栏。
3. **客户服务里放「全球布局 + 合作伙伴」**。菲美得背靠出口占比 96%、销往美日欧的集团体系，这个栏目是天然的信任背书。

**不建议照搬的**：投资者关系（公司非上市）、实时股价、高频 PR 新闻（其首页新闻流密度过高，中小企业没有这个内容产能，硬撑会显得空洞）。

## 5. 菲美得官网建设方案（建议稿）

### 5.1 网站定位

**面向海外与国内铸造件采购商的营销型外贸官网，中英双语（英文为主），核心任务是拿询盘。**

一句话价值主张（首屏用）：

> FAMED since 1987 ｜ Lost-foam & Sand Casting Components ｜ 80,000 t/yr Group Capacity ｜ 96% Exported to US, Japan & Europe
> （菲美得，始于 1987 年集团体系 ｜ 消失模与砂型铸造零部件 ｜ 集团年产能 8 万吨 ｜ 96% 出口美日欧）

### 5.2 栏目架构（建议 10 个一级栏目）

| # | 栏目 | 子栏目 |
|---|---|---|
| 1 | Home 首页 | — |
| 2 | About Us 关于我们 | 公司简介／工厂掠影／发展历程／企业文化 |
| 3 | Products 产品中心 | 按应用：工程机械配件、配重铁、齿圈铸件毛坯、塔吊大钩配重铁、电机机体、冶金焦化配套、阀门旋塞、机床配件 |
| 4 | Capabilities 制造能力 | 消失模造型线／中频电炉熔炼／机加工／热处理／涂装线／产能与规格表 |
| 5 | Quality 质量控制 | ISO9001／检测设备／检测流程／材质标准（HT150–HT300、球铁、ADI 等） |
| 6 | Applications 应用领域 | 工程机械／矿山机械／石油机械／铁路／电梯／减速机／机床 |
| 7 | Certificates 资质荣誉 | 高新技术企业、专精特新、科技型中小企业、绿色铸造企业、专利、纳税信用 A 级 |
| 8 | News 新闻资讯 | 公司动态／行业资讯／技术文章 |
| 9 | FAQ 常见问题 | 起订量／模具开发／交期／出口条款／材质与标准／样品 |
| 10 | Contact 联系我们 | 询盘表单／电话／邮箱／WhatsApp／工厂与办公地址／地图／中英双语联系人 |

### 5.3 首页模块顺序（建议）

1. 首屏大图或短视频 + 价值主张 + 「Get a Quote」按钮
2. 数字条：集团 38 年经验 ／ 8 万吨集团产能 ／ 6000 吨泊头基地产能 ／ 96% 出口占比（**数字须与集团口径一致，不可夸大**）
3. 产品分类入口（6–8 个卡片）
4. 应用领域图标区（6 个行业）
5. 「为什么选择菲美得」五点（工艺／检测／产能／认证／出口经验）
6. 生产与检测能力照片墙 + 视频看厂
7. 资质荣誉图标墙
8. 产品/案例精选（可脱敏展示：铸件照片 + 材质 + 单重 + 尺寸）
9. 新闻动态（3 条）
10. 询盘 CTA + 表单
11. 页脚：地址／电话／邮箱／社媒／二维码／备案号

### 5.4 关键功能清单（写进合同）

- **响应式**：手机端优先（海外流量移动端占比通常过半）
- **多语言**：中英双语起步，结构预留西语/俄语；英文内容须为**母语级翻译**，禁止机翻
- **SEO**：每页独立 TDK、产品页 URL 含关键词、sitemap.xml、robots.txt、结构化数据（Organization / Product）、绑定 Google Search Console
- **询盘系统**：表单字段（姓名/公司/国家/邮箱/电话/需求），提交后邮件通知 + 后台存档，含防垃圾机制
- **即时沟通**：WhatsApp 悬浮按钮、邮件订阅、可选在线客服
- **后台 CMS**：产品、新闻、案例可自行增删改，支持批量上传图片
- **速度与稳定**：图片 WebP 压缩、CDN 加速，首屏加载 < 2.5 秒
- **合规**：域名实名、ICP 备案（国内主机）或选用海外主机；GDPR 隐私政策与 Cookie 提示（面向欧洲客户需要）
- **统计**：Google Analytics / 百度统计双埋点

### 5.5 内容素材准备清单（交给设计前必须收齐）

| 类别 | 内容 | 来源 |
|---|---|---|
| 图片 | 厂区航拍、车间、消失模线、熔炼、机加工、涂装线、检测室、产品特写 | 需现场拍摄，现有素材不足 |
| 视频 | 3–5 分钟工厂介绍片（英文配音或字幕） | 需拍摄 |
| 文案 | 公司简介（中英）、产品描述、工艺说明、质控流程 | 可基于现有工商与资质资料撰写 |
| 资质 | 高新证书、专精特新、ISO9001、排污许可、专利证书扫描件 | 已有，需清理排版 |
| 数据 | 产能、最大铸件尺寸与单重、材质牌号、出口国家 | 已有（6000 吨、2000×1800×1200mm、2.5 吨、HT150–HT300） |
| 客户 | 可公开的合作伙伴 logo（**须获授权**） | 待确认 |

### 5.6 需要老板拍板的问题

1. 网站语言：只做英文（外贸导向），还是中英双语？
2. 服务器与域名：用国内主机（需备案）还是海外主机（免备案、海外访问快）？
3. 是否与「北京菲美得」集团官网形成母子站关系，还是独立门户？
4. 内容尺度：产能数据用集团口径（8 万吨）还是本厂口径（6000 吨）？合作伙伴 logo 能否公开？
5. 预算与工期，以及由哪家服务商承接（赤野科技 / 益商 / 其他）。
